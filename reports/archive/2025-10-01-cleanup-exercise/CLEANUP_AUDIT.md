3. Dynamic imports not captured by static analysis

**Recommendation:** 
- Expand entrypoint list to include:
  - All Alembic migrations
  - CLI commands (Click/Typer)
  - Background workers (Celery/RQ if present)
  - Test fixtures (conftest.py)
  - Pytest tests themselves
- Re-run orphan detection with expanded entrypoints
- Manually review top 20 "orphaned" modules for actual usage

#### Parse Errors
```
backend/config_helpers.py    - BOM character U+FEFF
backend/utils/utilities.py   - BOM character U+FEFF
```

**Action:** Remove BOM characters (UTF-8 with BOM → UTF-8):
```powershell
# Fix encoding
$files = @('backend\config_helpers.py', 'backend\utils\utilities.py')
foreach ($file in $files) {
    $content = Get-Content $file -Raw
    [IO.File]::WriteAllText($file, $content, (New-Object System.Text.UTF8Encoding $false))
}
```
