## Measurement and cost limits

The native corpus loader filters close timestamp and mapped entry source. It does **not** independently enforce complete cash-flow provenance, duplicate identity or all reconciliation-artifact exclusions, and `TradeRecord` does not persist an authoritative entry timestamp. A raw CLI count is therefore not automatically a clean qualified count. Read-only broker/ledger reconciliation must attest each prospective round trip and classify measurement gaps. If approximate, duplicate, carry-in or reconciliation rows remain unresolved, **withhold the forward verdict** rather than silently exclude inconvenient outcomes, rewrite history or claim a clean sample. This candidate does not change those eligibility policies.

The current code default is **3 bps round-trip**. The July authority, original-checkout `reports/RESEARCH_BRIEF_001_2026-07-29.md:15`, states: “Every result is net of a realistic cost profile (≥3 bps/side intraday equities; spread-aware where measurable).” That sets a **6 bps round-trip research minimum**; a 3 bps primary verdict would relax the documented floor.

The concrete proposed approval therefore uses **6 bps round-trip PRIMARY** for the new evaluation reports, with **3 bps round-trip only as a separately labeled native diagnostic comparison**, never the qualifying verdict. Invoke both forward CLIs with explicit process-local `ORGANISM_COST_BPS=6`, recording profile, cutoff and input hashes. A separate `ORGANISM_COST_BPS=3` report must say it is below the research floor and is diagnostic only. The fresh-process synthetic regression proves both CLIs load the 6 bps profile, compute the expected net cash flow and leave input bytes/parent environment unchanged.

No costing implementation or runtime environment changes. The draft manifest contains these proposed values but no approval. The distinction between unchanged native/runtime defaults and the research convention is deliberate. The brief’s separate feed/strategy suggestions are outside this candidate; IEX and the frozen decision surface remain unchanged.
