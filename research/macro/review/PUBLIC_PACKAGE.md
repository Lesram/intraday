# Public package and complete local evidence

The review was commissioned against a local companion research package. The full work product remains in this directory on the commissioning machine. The public pull request adds the authored reports, calculations, summary evidence, short critical claim samples, indicator contract, dashboard, refresh code and audit receipts. It does not publish the original source corpus or paid content.

The following immutable Phase A tables remain local because they contain lengthy verbatim transcript extraction. Their SHA-256 values remain in the original blind seal; no file was rewritten or deleted:

- `phase_a/directional_predicates.csv`
- `phase_a/pitch_sentences.csv`
- `phase_a/citation_like_sentences.csv`
- `phase_a/contradiction_pair_sample.csv`
- `phase_a/contradiction_sample_adjudicated.csv`

The curated contradiction/revision table and brief sampled claims are retained as critical evidence with dates, interpretations and caveats. The large candidate-pair table contains identifiers and dates only, not copied sentences.

On a fresh public checkout, the portable dashboard opens independently and live indicator retrieval uses public FRED endpoints. Historical replication and the full local-integrity validator additionally require the original companion source files and excluded tables, with the hashes specified in the manifest and seals. Missing companion files are not a successful integrity verification. Reviewers can still inspect the public methods, results, counts, assumptions and source links.

Transient dependencies, caches, archives, build directories and the temporary delivery index are also excluded from version control. Prospectively acquired readings remain in the local archive. No external dashboard hosting or scheduled job was installed.
