**What “final” means:** the identified research questions have been reconciled, material corrections have been incorporated into these documents, and the synthesis has received cross-agent peer review. It does not mean the commentators' predictive skill has been validated, missing paid material has been obtained, or a personal investment strategy has been established. The peer review is by AI agents, not independent human experts.

**What has changed:** research conclusions, specifications and supporting evidence within this directory. Earlier studies, sealed judgments, the existing dashboard and monitoring code remain preserved. Proposed software corrections are explicitly deferred to the user's later implementation decision. The snapshot is dated through 18 September 2026 with series-specific lags; this is not a live dashboard.

Run logs and validation receipts distinguish new checks from prior test evidence.
