    fix(scripts): default standalone scripts to organism_brain_sandbox/
    
    Both run_hft_organism.py and run_breakout_organism.py previously defaulted
    to brain_dir="organism_brain", which is the same directory bind-mounted into
    the live paper-trading container. A manual invocation of either script on
    the host would write directly to the live container's brain storage through
    its own brain.save() path, bypassing the live engine entirely.
    
    This is the most plausible trigger for the Apr 8 02:08 UTC brain wipe
    incident where a zeroed manifest was written without any organism save-log
    entry. The root cause investigation proved that the wipe manifest matches
    byte-for-byte what these scripts would produce when called with fresh
    learner/signal_gen objects.
    
    Change defaults to organism_brain_sandbox/ so scripts cannot accidentally
    mutate the live brain. Explicit --brain-dir organism_brain still works
    for intentional use.
